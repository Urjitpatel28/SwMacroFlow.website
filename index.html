Features

Everything you need to automate SOLIDWORKS busywork

No add-in to register. No menu item to unregister. Just a tool that drives SOLIDWORKS from outside.

🔗

Chain multiple macros

Queue up as many macros as you like, in the order they should run — each file opens once, every ticked macro runs against it, then it closes.

📂

Batch across folders

Browse a folder (recursively, if you like), drag & drop, or add files one by one. Parts, assemblies and drawings are sorted automatically.

✨

AI Copilot side panel

Ask Copilot to build your macro chain, scan a folder, or write a new macro for you — every destructive action needs your approval first.

🧩

Zero add-in installs

SwMacroFlow joins a SOLIDWORKS session you already have open, or starts one — nothing is ever installed into SOLIDWORKS itself.

📚

Bundled macro library

Ships with a library of ready-to-use macros for common jobs — export, cleanup, and more — plus your own macros alongside them.

🔄

FAQ

Good to know before you get started

Which SOLIDWORKS versions does this support?

SwMacroFlow isn't locked to one release — it works with any SOLIDWORKS version you already have installed and licensed (x64). It joins the SOLIDWORKS session on your machine rather than shipping its own.

How do I get SwMacroFlow?

Download the Windows installer directly from the release page. SwMacroFlow is free for everyone, with no registration or access request needed.

Do I need to register?

No. SwMacroFlow does not require sign-in, registration, or an access key.

Can I use it on more than one computer?

Yes. There is no SwMacroFlow seat limit. Install it on the Windows machines where you need it, while using your own licensed SOLIDWORKS installation.

Does SwMacroFlow update itself?

Yes. New builds can be delivered through the app's built-in auto-updater when updates are available.

Do I need administrator rights?

No. SwMacroFlow uses a per-user installation and is designed to run without an administrator elevation prompt.

Does SwMacroFlow install anything into SOLIDWORKS?

No. It runs as a separate application and drives SOLIDWORKS from outside — there's no add-in to register or unregister.
