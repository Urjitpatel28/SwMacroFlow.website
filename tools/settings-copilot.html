Settings — Copilot (Bring Your Own AI)

Provider

  • OpenAI, Anthropic, xAI (Grok), Google Gemini, or LM Studio running on your own machine.
  • Each keeps its own key, model and URL, so switching back and forth loses nothing.
  • Images work everywhere; PDFs on OpenAI and Anthropic.

API key

  • Yours, from your own provider account. SwMacroFlow has no server in the middle and no key of its own.
  • Encrypted before it is stored, to this Windows account on this machine — not plain text in a screen share, a registry export or a backup.
  • It is only ever sent to the provider you picked, and it is never written to the log.
  • Clear the box and Save to delete it. No box at all for LM Studio, which authenticates nobody.

Save

  • Writes it, then reads it straight back — so a failure shows up here rather than on your next message.
  • A blank model falls back to the provider's own default.

Base URL

  • Blank is normal. The grey text is the provider's own endpoint, shown so you know what blank means — it is not a value.
  • Fill it in for LM Studio on a port of your choosing, or for an OpenAI-compatible gateway: Azure, OpenRouter, LiteLLM, a company proxy.

Model & the
refresh arrow

  • Free text, so a model released next month needs a new build of nothing — type its name.
  • ↻ lists the models your key can actually use. It asks with what is typed now, not what is saved, so you can test a key before committing it.
  • 40 models available is however many came back.

The model chips

  • Suggestions to start from — click one and it fills the box above.
  • A successful refresh replaces them with the real list. A failed one leaves them alone and turns the line above red.

💡 Tips

  • The four cloud providers need a key before the Copilot will answer. LM Studio does not — point it at your own machine and nothing leaves it.
  • The Copilot is not just chat: it can read your macros, build the chain, add files, run the batch and schedule one. It asks before anything destructive.
  • Start with a small, cheap model. The work it does here is reading macros and filling in a setup, not writing an essay.
