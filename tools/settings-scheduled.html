Settings — Scheduled Tasks (Run It Tonight)

One card,
one saved batch

  • They are not made here. Set the batch up in the main window, then press the clock beside Run Batch.
  • Once, Daily, Weekly, Monthly, or every N minutes.
  • Saving takes a snapshot: the macros, the inputs, the file list, and which SOLIDWORKS to use.

When it runs,
and whether it did

  • Runs once at... becomes Done only when a run was really recorded — a machine that was asleep says Missed instead of pretending.
  • Closes app when done: SwMacroFlow exits after the run. Forced for repeating tasks, because Windows counts a task as still running while its window is open, and every later trigger would do nothing.

Restore into
the setup

  • Loads that task's saved macros, inputs and files back into the main window, so you can see exactly what it will run.
  • Changes no timing and cancels nothing.

Edit & Run Now

  • Edit reopens the schedule dialog. Timing only — the saved batch is untouched.
  • Run Now starts it through Windows this second without changing the schedule. It is the real launch, connect, run, exit path, so it answers "will this actually work at 3am?"
  • It does start a second SwMacroFlow, and very likely a second SOLIDWORKS. It asks first.

Update From
Current Setup

  • Re-captures whatever the main window holds now into this task, leaving its timing alone.
  • Greyed until that setup is actually runnable: a macro ticked, files in scope, every macro and file still on disk, nothing running.
  • This is how you add newer files to a schedule.

Remove

  • Deletes the Windows Task Scheduler entry and the saved snapshot. It asks first.
  • Nothing that already ran is undone by it.

💡 Tips

  • These are real Windows Task Scheduler entries, so SwMacroFlow does not have to be open — Windows starts it.
  • You do have to be logged on, and it will not wake a sleeping machine. A machine that was off runs the batch when it comes back.
  • The file list is frozen when you schedule it. Files dropped into the folder afterwards are not picked up until you press Update From Current Setup.
  • Try it with Run Now once, in the day, before you trust it overnight.
