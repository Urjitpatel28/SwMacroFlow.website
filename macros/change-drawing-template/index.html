Change Drawing Template: swap the .slddrt sheet format

Applies a .slddrt sheet format to one sheet, several named sheets, or every sheet in a drawing, then rebuilds and saves.

Drawing

DRW Drawings

Download Change Drawing Template.swp Get SwMacroFlow

Put the downloaded file in this folder, then open SwMacroFlow and choose it from the library.

%LOCALAPPDATA%\SwMacroFlow\macros

Runs per file, on drawings. Parts and assemblies are reported as unsupported.

Inputs

FieldPurpose
SheetNameA sheet name, or a comma-separated list. Blank means every sheet.
TemplatePathThe .slddrt sheet format to apply.

SheetName examples: "" for all sheets, Sheet1 for one, Sheet1, Sheet2 for several.

Results

Reports how many sheets were updated. A file where no sheet could be updated is reported as an error; a partial update is reported with the last error in the message.

This macro runs by hand in the SOLIDWORKS VBA editor like any other. To run it across a whole folder of parts, assemblies or drawings unattended, use it inside SwMacroFlow - a free Windows app that chains macros and batches them over hundreds of files.
